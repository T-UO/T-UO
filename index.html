About

Hi, I'm Tagbo — a Master's student in Computer Science at Northwestern University.

My interests are in computer vision, machine learning, and high-performance computing, with a growing focus on 3D vision and geometric understanding. I'm particularly interested in how computational systems can extract useful information about the structure and geometry of the physical world from visual data.

My technical background spans parallel computing, parallel architectures, embedded systems, and systems programming. Through coursework and projects, I've worked with C++, CUDA, multithreaded programming, microcontrollers, image processing algorithms, and machine learning.

I'm currently developing my interests in areas such as 3D surface reconstruction, geometric computer vision, scene understanding, and perception for embodied systems.

Before pursuing computer science, I worked in capital markets. I'm interested in combining my engineering and quantitative background with my developing expertise in computer vision to solve challenging real-world problems.

Projects

Parallel Sobel Edge Detection Pipeline

Developed a parallel Sobel edge-detection pipeline using a producer-consumer architecture with POSIX threads and shared and partitioned ring-buffer work queues. Evaluated how thread count and queue organization affected execution time, throughput, and contention, and implemented an exploratory CUDA version to compare CPU and GPU execution.

C · C++ · CUDA · POSIX Threads · Parallel Computing · Image Processing

Teleoperation Glove: Embedded Sensing and Communication

Developed the sensing and communication components for a teleoperation project using multiple IMUs and nRF52833 microcontrollers. Integrated wrist, forearm, and upper-arm orientation sensors over I2C and UART, processed orientation data on embedded hardware, and implemented wireless transmission of sensor measurements using 802.15.4.

Embedded C · nRF52833 · IMUs · I2C · UART · 802.15.4

OpenStreetMap Data Processing and Search

Developed a C++ application to process OpenStreetMap data for Northwestern's Evanston campus. Implemented building and amenity search, geographic queries, and location calculations while improving node lookup efficiency through binary search and reference-based parameter passing.

C++ · OOP · OpenStreetMap · XML · Data Structures · Binary Search
