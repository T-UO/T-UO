About

Hi, I'm Tagbo — a Master's student in Computer Science at Northwestern University.

My primary interests are in computer vision, 3D vision, and machine learning. I'm particularly interested in how computational systems can recover and understand the geometry of the physical world from visual information.

I'm currently exploring problems involving 3D surface reconstruction, geometric computer vision, scene understanding, and perception for intelligent and embodied systems.

My broader technical background includes high-performance computing, parallel computing, embedded systems, computer architecture, and systems programming. I've worked with C++, CUDA, POSIX threads, microcontrollers, computer vision algorithms, and machine learning.

Before pursuing computer science, I worked in capital markets. I'm interested in bringing together my engineering background, quantitative experience, and growing specialization in computer vision to work on challenging real-world problems.

Projects

Parallel Sobel Edge Detection Pipeline

Developed a parallel image-processing pipeline for Sobel edge detection using producer-consumer architectures, POSIX threads, shared and partitioned work queues, and CUDA GPU acceleration. The project explored scalability, synchronization overhead, queue contention, and CPU/GPU performance.

C · C++ · CUDA · POSIX Threads · Parallel Computing · Computer Vision

Teleoperation and Embedded Sensor System

Built a microcontroller-based teleoperation system using multiple inertial measurement units to capture arm and wrist orientation. Sensor information was processed on embedded hardware and transmitted wirelessly to control a remote robotic system.

Embedded C · nRF52833 · IMUs · I2C · UART · Wireless Communication
