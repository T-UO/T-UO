About

Hi, I'm Tagbo — a Master's student in Computer Science at Northwestern University.

My interests are in computer vision, machine learning, and high-performance computing, with a growing focus on 3D vision and geometric understanding. I'm particularly interested in how computational systems can extract useful information about the structure and geometry of the physical world from visual data.

My technical background spans parallel computing, parallel architectures, embedded systems, and systems programming. Through coursework and projects, I've worked with C++, CUDA, multithreaded programming, microcontrollers, image processing algorithms, and machine learning.

I'm currently developing my interests in areas such as 3D surface reconstruction, geometric computer vision, scene understanding, and perception for embodied systems.

Before pursuing computer science, I worked in capital markets. I'm interested in combining my engineering and quantitative background with my developing expertise in computer vision to solve challenging real-world problems.

Projects

Parallel Sobel Edge Detection Pipeline

Developed a parallel image-processing pipeline for Sobel edge detection using producer-consumer architectures, POSIX threads, shared and partitioned work queues, and CUDA GPU acceleration. The project explored scalability, synchronization overhead, queue contention, and CPU/GPU performance.

C · C++ · CUDA · POSIX Threads · Parallel Computing · Image Processing

Teleoperation and Embedded Sensor System

Built a microcontroller-based teleoperation system using multiple inertial measurement units to capture arm and wrist orientation. Sensor information was processed on embedded hardware and transmitted wirelessly to control a remote robotic system.

Embedded C · nRF52833 · IMUs · I2C · UART · Wireless Communication
